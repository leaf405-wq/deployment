# 之之风速

之之风速是索伦邸中国区的奢品运营台。它不帮你把流量做成成交，它把一天收成三件决定：谁该被联系，谁不该被推销，哪一席必须空着。

样本人物与单品都是虚构的。语气模型和名册规则在浏览器里运行，客户内容不会发到外部模型。

## 六页怎么用

1. **晨会**看全价、被拒绝的议价，以及今天的三件决定和一件明确不做的事。
2. **名册**按场合、沉默和禁忌排序。打开一个人，先读「不要」，再抄短信。短信不会自动发出。
3. **内容**选定单品、渠道和语气。小红书与口播不写价格，也不写某一个人的私事。
4. **体验**给静水私享、夜航预约日和成都护理场留席。配不上的人会写明为什么不请。
5. **方法**是这套运营的六条顺序：价格、名册、体验、内容、顾问、模型边界。
6. **孪生**看五十家店在同一时刻的人流、成交额、类别、客单价、转化率和流失率，并给出相对上月同日同一分钟的环比。店内平面按柜位画成二维模型，鼠标放上去看这一分钟的停留、件数和金额。页面后段是同一家店的虚拟四间：客户体验（线上门店、远程导购、产品转台、样衣试戴、文化展陈）、门店运营（热力、动线、顾问效率、排队、设备）、商品与陈列（空柜、合规、库存、两套方案）、品牌内容（巡展、新品、工艺、十二只限量）。全国地图、平面和虚拟层每一分钟整点一起换。问句在浏览器里回答，不追踪个人，也不接摄像头。

晨会上的「列入今日」、名册里的「已联系」和席位，记在这台浏览器里。

## 在自己的电脑上运行

需要 Node.js 20 或以上。在这个项目的文件夹里打开终端，不要在另一台机器上找这个地址。

日常开发：

```bash
npm install
npm run dev
```

正式在本地跑：

```bash
npm install
npm run build
npm start
```

然后用这台电脑自己的浏览器打开 [http://127.0.0.1:3847/twin](http://127.0.0.1:3847/twin)。晨会在 [http://127.0.0.1:3847](http://127.0.0.1:3847)。这个地址只对正在运行命令的那台电脑有效。

不需要账号或密钥。样本数和店内平面都在本机计算。全国地图的底图来自 OpenFreeMap，第一次打开时要能访问外网；店内平面不依赖它。

```bash
npm test
npm run lint
```

## 换成自己的品牌

单品档案在 `src/lib/maison.ts`，话术与取舍规则在 `src/lib/engine.ts`。正式使用时，名册应留在品牌自己的环境里，模型只接收顾问确认过的字段。这里故意没有自动发送。

字体为 Noto Sans SC、Noto Serif SC 与 Cormorant Garamond，按 SIL Open Font License 随仓库分发，许可见 `public/fonts/`。

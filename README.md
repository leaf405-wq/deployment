# Apex Circuit

可在 Mac（以及任意现代浏览器）运行的俯视赛车游戏：每次随机生成一条封闭上赛道，支持方向键加速 / 刹车 / 转向，带抓地力与漂移手感。

## 操作

| 按键 | 作用 |
|------|------|
| `↑` / `W` | 加速 |
| `↓` / `S` | 刹车 / 倒车 |
| `←` `→` / `A` `D` | 转向 |
| `R` | 随机生成新赛道 |

跑完 **3 圈** 完赛。冲出赛道会明显失速，尽快回沥青路面。

## 本地运行（Mac）

需要已安装 [Node.js](https://nodejs.org/)（建议 20+）。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 [http://127.0.0.1:45321](http://127.0.0.1:45321)）。

构建静态资源：

```bash
npm run build
npm run preview
```

## 玩法提示

- 高速过弯时转向会变“沉”，提前收油或轻点刹车更稳。
- 侧滑时会出现胎痕；抓地不够会甩尾。
- 点右上角 **随机新赛道** 或按 `R` 换一条布局。
